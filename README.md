# Gulliver's Travels

Welcome to **Gulliver's Travels**, a comprehensive blog and travel service website designed to inspire and assist travelers around the world. Our platform offers engaging travel stories, helpful travel tips, and booking services to make your travel planning seamless and enjoyable.

## Features

- **Travel Blog**: Read articles and travel stories from experienced travelers.
- **Travel Booking**: Book tour packages directly from the site.
- **User Reviews**: Share and read reviews of destinations and travel services.

## Getting Started

### Prerequisites

To get a local copy up and running, you will need the following tools installed on your machine:

- [Git](https://git-scm.com/)
- [PHP](https://www.php.net/)
- [XAMPP](https://www.apachefriends.org/)
- [Cloudinary](https://cloudinary.com/)
- [MySQL](https://www.mysql.com/)
- [Composer](https://getcomposer.org/)

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/gullivers-travels.git
   ```
2. Navigate to the project directory:
   ```sh
   cd gullivers-travels
   ```
3. Install the necessary dependencies using Composer.
